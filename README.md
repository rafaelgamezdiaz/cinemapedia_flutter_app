## Prod
Para cambiar nombre de la aplicacion
- instalamos el paquete: change_app_package_name
- ejecutamos el comando:

        ```dart run change_app_package_name:main com.ragadi.infocinex```


Para cambiar el icono de la aplicacion
- Instalamos el paquete flutter_launcher_icons 

  ```dart run flutter_launcher_icons```
